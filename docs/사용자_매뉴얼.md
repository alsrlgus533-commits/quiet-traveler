# 조용한 여행자 사용자 매뉴얼

컴퓨터를 잘 몰라도 쓸 수 있도록, 켜는 법부터 질문하는 법까지 순서대로 적었습니다.

## 1. 켜기 (처음 한 번)

1. **Python 설치**: python.org 에서 Python 3.10 이상을 설치합니다. 설치 화면에서 "Add Python to PATH"를 꼭 체크합니다.
2. **압축 풀기**: 받은 ZIP 파일을 원하는 폴더에 풉니다.
3. **명령 창 열기**: 압축을 푼 폴더에서 주소창에 `cmd` 를 입력하고 Enter 를 누릅니다.
4. **필요한 것 설치**: 아래를 입력하고 Enter.
   ```
   pip install -r requirements.txt
   ```
5. **키 넣기**: `.env.example` 파일을 복사해 이름을 `.env` 로 바꾸고, 메모장으로 열어 `UPSTAGE_API_KEY=` 뒤에 업스테이지 키를 붙여 넣고 저장합니다.

## 2. 실행하기 (매번)

```
python -m agent.server
```

"조용한 여행자: http://localhost:8000" 이 보이면 브라우저(크롬·엣지)에서 **http://localhost:8000** 을 엽니다. 끌 때는 명령 창에서 Ctrl+C.

## 3. 화면 쓰는 법

열면 바로 **지금 내 근처 한산한 곳 6곳**이 사진 판으로 보입니다. 스크롤 없이 한 화면에 다 들어갑니다.

| 위치 | 하는 일 |
|---|---|
| 날짜 | 한라산 분화구 아래에 고른 날짜가 크게 보입니다. 날짜(▾)를 누르면 달력이 열려 예측이 있는 30일 안에서 바로 고를 수 있습니다(날마다 붐빔 점·날씨). ‹ › 로 하루씩 넘기고, "오늘 제주는 여행객으로 붐벼요"처럼 그날 제주 전체 붐빔과 날씨가 함께 보입니다. 해가 진 뒤에 열면 내일이 먼저 보입니다 |
| 사진 판 6곳 | 사진, 이름, 테마·차로 걸리는 시간, 한산함만 보입니다. 오늘은 지금 시각, 다른 날은 장소마다 가장 한산한 때 기준으로 고릅니다. 위치를 허용하면 가까운 곳을 앞에, 비 오는 날은 오름을 빼고 숲길·마을을 앞에 둡니다. 같은 테마는 2곳까지 |
| 위치 | 열 때 한 번 위치를 묻습니다. 위치는 이 기기 안에서만 쓰고 어디에도 보내지 않습니다. 거부하거나 제주 밖이면 제주 전체에서 한산한 곳을 고르고, "내 위치로 보기"로 다시 찾을 수 있습니다 |
| 장소 상세 | 사진을 누르면 열립니다. 그림 6칸(지금 사람·가장 조용한 때·주차·걷기·날씨·머무는 시간)으로 장단점을 한눈에 보고, **자동차**·**대중교통** 그림을 누르면 카카오맵 길찾기가 바로 열립니다(위치를 모르면 카카오맵에서 출발지를 고릅니다) 그림 6칸 아래에 **장애인 편의시설**(장애인 주차·장애인 화장실·휠체어 대여·시각/청각장애인 안내 등)이 비짓제주 무장애 정보 기준으로 나옵니다. 정보가 없는 곳은 '아직 정보가 없어요'(시설이 없다는 뜻은 아님) |
| 아래 메뉴 | 반투명 막대에 **추천**(첫 화면 맨 위로)·**저장**·**내 코스**·**물어보기**(AI 가 켜져 있을 때). 저장 아이콘에 저장한 곳 수가 붙습니다 |
| ♡ 저장 | 장소 상세 오른쪽 위 ♡ 저장. 저장한 곳은 이 기기 안에만 남습니다. **저장** 메뉴에서 모아 보고 ♥ 로 뺍니다 |
| 내 코스 | **여행 기간(하루·이틀·사흘)**을 고르면 저장한 곳을 가까운 곳끼리 날짜별로 나눠(하루 최대 6곳, 날마다 비슷한 수) 날마다 코스와 카카오맵 길안내를 따로 보여 줍니다. 하루일 때는 저장한 곳(최대 6곳)을 한산한 시간과 이동 시간에 맞춰 순서를 짭니다. 오늘이면 지금 출발. 다른 날은 먼저 "몇 시에 출발하실 거예요?"라고 묻고(가장 한산해지는 시각에 '가장 한산' 표시), 고른 시각에 맞춰 장소마다 도착할 때 한산한 순서로 짭니다. '시각 바꾸기'로 다시 고를 수 있습니다. 해 지기 전에 못 들르는 곳은 뺍니다. 내 위치를 알면 거기서 출발하고, **카카오맵으로 코스 길안내**로 경유지까지 한 번에 엽니다. 저장이 1곳 이하이면 "한산한 곳 3곳으로 코스 채우기". 저장한 곳이 적은 날은 근처(20km 안) 한산한 곳으로 하루 4곳까지 **추천**으로 채우고, '저장한 곳만 보기'로 끌 수 있습니다 |

AI 가 켜져 있으면(로컬·서버 실행, 키 있음) 아래 메뉴에 **물어보기**가 생깁니다. 누르면 대화 칸이 아래에서 올라오고, 답 속 장소 이름을 눌러 상세를 봤다가 닫으면 대화로 돌아옵니다.

예전의 지도·코스·목록 화면은 숨겨 두었습니다(코드는 `index.html` 에 남아 있어 다시 켤 수 있습니다).

## 4. AI 에게 묻기 (첫 화면의 '물어보세요' 판)

"물어보세요" 칸에 평소 말하듯 적고 **보내기**(또는 Enter)를 누릅니다. 예시 버튼을 눌러도 됩니다.

| 이런 걸 물어보세요 | 예시 |
|---|---|
| 한산한 곳 찾기 | "이번 토요일 비 안 오고 덜 붐비는 숲길 어디야?" |
| 코스 짜기 | "성산 쪽에서 10시부터 반나절 코스 짜줘" |
| 한 장소 알아보기 | "다음 주에 성산일출봉 가장 한산한 날은?" |
| 날씨 | "이번 주 제주 날씨 어때?" |
| 분석 (담당자용) | "다음 주 평소보다 붐빌 관광지 10곳 순위 알려줘" |
| 요즘 실제 붐빔 | "요즘 성산일출봉 실제로 붐벼? 무슨 요일이 한산해?" |
| 지역 요일 패턴 | "구좌읍은 무슨 요일에 사람이 적어?" |
| 제주 카드 데이터 | "구도심은 하루 중 언제 카드 결제가 많아?" |

- 답에 나온 장소 이름을 누르면 그 장소의 상세 화면이 열립니다.
- 오늘이 아닌 날의 코스를 시각 없이 물으면(예: "토요일 코스 짜줘") 먼저 "몇 시에 출발하실 거예요?"라고 묻습니다. "9시"처럼 답하면 앞 질문의 날짜와 합쳐 바로 코스를 짭니다.
- 답에 장소가 나오면 "이 중에서 마음에 드는 곳을 **저장해 드릴까요?**"라고 묻습니다. ♡ 로 고르고 **저장해 줘**(또는 "응")를 누르면 저장하고, 이어서 "**내 코스에 반영해 드릴까요?**"에 동의하면 내 코스가 열립니다. 그날 붐비는 곳은 처음엔 고르지 않은 채로 둡니다. 동의 없이 저장하지 않습니다.
- 답 아래 "조회한 데이터"에 AI 가 어떤 데이터를 봤는지 나옵니다.
- 와이파이·유동인구처럼 지난 기록을 쓴 답에는 그 기간이 함께 나옵니다.
- 이어서 물어보면 앞의 대화를 기억하고 답합니다. 새로 시작하려면 페이지를 새로고침합니다.

## 5. 알아 두면 좋은 점

- **한산함과 주차는 추정**입니다. 관광공사 30일 예측과 시간대 패턴으로 계산한 값이라 실제와 다를 수 있습니다.
- 날씨는 기상청 예보(약 10일)를 쓰고, 그 뒤 날짜는 Open-Meteo 예보로 채웁니다.
- 비 예보가 있는 날은 오름을 덜 권하고 숲길·마을을 먼저 권합니다.
- 길안내 버튼은 카카오맵·네이버 지도 웹 페이지를 엽니다. 휴대폰에서는 거기서 앱으로 넘어갈 수 있습니다.

## 6. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "AI 키가 없어 대화가 꺼져 있어요" | `.env` 의 `UPSTAGE_API_KEY` 를 확인하고 서버를 다시 켭니다 |
| "서버에 연결하지 못했어요" | 명령 창에서 `python -m agent.server` 가 켜져 있는지 확인합니다 |
| `pip` 를 찾을 수 없음 | Python 설치 때 "Add Python to PATH" 를 체크했는지 확인하거나 `python -m pip install -r requirements.txt` |
| 포트 8000 사용 중 | `python -m agent.server --port 9000` 후 http://localhost:9000 |
| 숫자가 예전 날짜 기준 | 최신 예측을 받으려면 `.env` 에 `TOUR_API_KEY`(와 `KMA_API_KEY`)를 넣고 `python fetch_forecast.py` |
